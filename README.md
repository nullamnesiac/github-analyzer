# GitHub Profile Analyzer

A command-line Python application that interfaces with the GitHub REST API to fetch and analyze repository data for any public GitHub profile.

## Features
- Fetches real-time profile repository metadata.
- Calculates aggregate metrics including total public repositories and total stargazers.
- Aggregates and ranks primary programming languages by repository frequency.
- Built with error handling for non-existent users and network-level exceptions.

## Tech Stack
- **Language:** Python
- **Libraries:** `urllib`, `json`, `ssl`
